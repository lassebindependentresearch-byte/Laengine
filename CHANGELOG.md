# Laengine v0.1

First public release of the Strix Halo Vulkan build for Ling-3.2-air.

- Packed recurrent projections and convolutions.
- Grouped MLA attention and efficient mask handling.
- Prompt lookup and GPU-side rollback for complete-file edits.
- A 266,240-token long-context profile, OpenAI Chat Completions, and a Hermes configuration example.
- Build, model conversion, and reproducible benchmark scripts.
